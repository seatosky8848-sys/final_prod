# AJAY LALWANI — VISION BEYOND SIGHT

## Premium Documentary Storytelling Website

Build a world-class cinematic documentary website for Ajay Lalwani, a visually impaired endurance athlete preparing for the historic Sea-to-Sky Everest Mission.

The final result should feel like a blend of:

- Rolex Explorer Campaigns
- National Geographic Features
- Patagonia Expedition Journals
- A24 Documentary Experiences
- Apple Editorial Storytelling
- Monocle Magazine Layouts

This is NOT a portfolio website.

This is NOT a sports website.

This is NOT a startup landing page.

This is a premium documentary platform focused on resilience, human spirit, endurance, purpose, and legacy.

Every section should feel handcrafted by a top-tier creative agency.

The experience should be timeless, elegant, cinematic, and emotionally powerful.

---

# CORE BRAND POSITIONING

Ajay Lalwani is not selling a product.

He is documenting a mission.

The website exists to:

- Tell a remarkable human story
- Build emotional connection
- Attract sponsors and partners
- Inspire audiences
- Document a historic journey
- Create long-term credibility

Visitors should feel:

1. Curiosity
2. Respect
3. Inspiration
4. Emotional connection
5. Desire to support the mission

# ANIMATION RULES

Use Framer Motion.

Allowed:

- Fade reveals
- Image reveals
- Counter animations
- Hero parallax
- Underline hover animations

Not Allowed:

- Bounce effects
- Oversized parallax
- Excessive motion
- Startup-style animations
- Floating decorative elements

Motion should feel cinematic and intentional.

# ACCESSIBILITY

This project represents a visually impaired athlete.

Accessibility must be exceptional.

Requirements:

- Semantic HTML
- Keyboard navigation
- Proper heading hierarchy
- High contrast ratios
- Focus indicators
- Screen reader support
- Accessible forms
- Alt text for all imagery

Accessibility should feel integrated into the experience.
